# 🤖 Gmail Forwarding Bot for Telegram

**Free • Open Source • Telegram + Web Dashboard**

Manage authorized Gmail accounts through Telegram with a simple, controlled workflow. Admins can approve users, assign specific emails, set expiry dates, and let users view forwarded messages without giving everyone unrestricted access.

---

## ✅ What it does

- 👥 Approve or deny user access requests
- 📬 Assign specific email accounts to approved users
- 🔐 Control access with permissions and expiry dates
- 📱 Let users view assigned emails in Telegram
- 🌐 Provide an optional web dashboard for users and admins
- 🔁 Support renewals, replacements, and access removal
- 💾 Create backups and review access activity
- 🔌 Offer an authenticated API for authorized integrations

---

## 🛡️ Admin features

- Manage users, sub-admins, and permissions
- Assign emails individually or in bulk
- Set, edit, and renew expiry dates
- View active, expired, and unassigned email accounts
- Send notifications and broadcasts
- Create backups of bot data

---

## 🌐 Web interface

- Use the bot from a browser without requiring Telegram for web-only users
- Manage users and email assignments from the admin dashboard
- Search assigned emails through the authenticated web interface

---

## 🔒 Privacy and responsible use

Use this bot only with Gmail accounts and messages that you own or are explicitly authorized to manage. Never share your Gmail password, bot token, API keys, or environment variables publicly.

**Self-host it, control access, and keep your email workflow organized.**
