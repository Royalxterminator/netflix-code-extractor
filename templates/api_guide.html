04

Ready to copy

Code examples

curl -X POST \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"email":"shared@example.com","choice":"login_code"}' \
  {{ api_base_url }}/api/fetch
import requests

response = requests.post(
    "{{ api_base_url }}/api/fetch",
    headers={"Authorization": "Bearer YOUR_API_KEY"},
    json={"email": "shared@example.com", "choice": "login_code"},
    timeout=30,
)
print(response.json())
const response = await fetch(
  "{{ api_base_url }}/api/fetch",
  {
    method: "POST",
    headers: {
      "Authorization": "Bearer YOUR_API_KEY",
      "Content-Type": "application/json"
    },
    body: JSON.stringify({ email: "shared@example.com", choice: "login_code" })
  }
);
console.log(await response.json());

Errors & security

200Request successful
400Invalid request data
401Missing or invalid API key
403Permission or assignment denied
500Server-side error
⚠
Protect your API keys

Never commit keys to Git, place them in frontend JavaScript, or share them in screenshots. If a key is exposed, revoke it from Profile immediately and create a replacement.
